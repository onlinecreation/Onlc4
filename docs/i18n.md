# Langues de l'interface

Les plugins ONLC sont écrits en français : les chaînes du code **sont** les clés de traduction.
Sans paquet de langue chargé, l'interface est donc en français, sans configuration.

Trois paquets sont livrés :

| Fichier | Codes déclarés | Langue |
|---|---|---|
| `langs/onlc/fr.js` | `fr`, `fr_FR` | français (paquet vide : les clés font foi) |
| `langs/onlc/en.js` | `en`, `en_GB`, `en_US`, `en_CA`, `en_AU` | anglais |
| `langs/onlc/es.js` | `es`, `es_ES`, `es_MX`, `es_419` | espagnol |

## Charger une langue

Le paquet est un simple script à inclure **avant** `hugerte.init()` :

```html
<script src="/hugerte/hugerte.js"></script>
<script src="/hugerte/langs/onlc/es.js"></script>
<script>
  hugerte.init({
    selector: '#contenu',
    language: 'es',
    plugins: 'onlcblocks onlcmedia onlcwidgets onlcshortcodes onlcicons onlclink onlcspacer'
  });
</script>
```

Ces fichiers appellent `hugerte.addI18n()`, qui **fusionne** : ils cohabitent sans conflit avec le
paquet de langue de HugeRTE lui-même, qui traduit l'interface du cœur et du thème. Chargez les
deux pour une interface entièrement traduite.

Le nom du fichier est volontairement rangé sous `langs/onlc/` plutôt que `langs/` : un paquet
officiel `langs/es.js` n'est ni remplacé ni écrasé.

## Ce qui est traduit

456 chaînes, couvrant les huit plugins : intitulés de champs, titres de dialogues, infobulles
des boutons, noms et descriptions des blocs, phrases d'explication, messages d'état de la
médiathèque et du sélecteur de lieu.

Ne sont pas traduits, volontairement :

* les **contenus produits** — le nom des mois du bloc calendrier, par exemple, suit la langue
  d'écriture du site et non celle de l'interface ;
* les **valeurs techniques** — `nofollow`, `noopener`, les noms de classes css ;
* les **marques** — Facebook, LinkedIn, PayPal, OpenStreetMap.

## Ajouter ou corriger une traduction

Les paquets sont générés à partir d'un seul fichier, `modules/hugerte/tools/i18n/translations.json`,
qui associe à chaque chaîne française sa traduction anglaise puis espagnole :

```json
{
  "Ajouter un bloc": [ "Add a block", "Añadir un bloque" ]
}
```

Après modification :

```sh
node modules/hugerte/tools/openmoji/build-i18n.js
yarn example-build
```

## Ajouter une langue

Ajoutez une entrée dans le tableau `languages` du générateur — le fichier à produire, les codes
qu'il déclare et la position de la traduction dans le tableau — puis une troisième valeur à
chaque ligne de `translations.json`.

## Traduire ses propres blocs

Les blocs ajoutés par un projet (`onlc_widgets_custom`, `onlc_shortcodes_custom`) passent par le
même mécanisme : leurs intitulés sont traduits s'ils figurent dans un paquet chargé.

```js
hugerte.addI18n('es', {
  'Horaires d’ouverture': 'Horario de apertura',
  'Du lundi au vendredi': 'De lunes a viernes'
});
```
