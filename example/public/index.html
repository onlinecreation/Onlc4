ONLC 4 — démonstration

Tous les plugins ONLC branchés sur des API simulées : médias, liens, icônes et éditeur d’images.

API médias API liens API icônes Éditeur Pixel

Que tester ?

  • Blocs : survolez un paragraphe, déplacez-le avec la poignée, utilisez les « + » pour insérer une ligne de colonnes.
  • Colonnes : cliquez dans une colonne — la barre de la ligne propose les sept dispositions, sous forme de schémas.
  • Médiathèque : bouton Bibliothèque — barre latérale, fil d’Ariane, glisser-déposer, retouche dans Pixel.
  • Images : la première utilise l’effet parallaxe, la seconde une largeur en pourcentage — le HTML enregistré ne contient ni width ni height.
  • Médias inertes : vidéo, page intégrée, carte, PDF et galerie s’affichent en vignette. Un clic sélectionne le bloc, « Modifier le bloc » l’ouvre.
  • Carte : le formulaire cherche une adresse (Nominatim), l’aperçu est un damier de tuiles OpenStreetMap, la page publiée reçoit Leaflet et ses imports CDNJS.
  • Calendrier : grille du mois d’avril 2026 avec ses rendez-vous, modifiables ligne par ligne.
  • Codes courts : [MenuSite], [Contact], [SocialButtons]… s’affichent en blocs explicites et repartent à l’identique.
  • Emojis : tapez un emoji — il devient un dessin OpenMoji, identique sur tous les appareils.
  • Script & source : le contenu contient alert("hello") — aucune alerte ne s’affiche, le jeton jaune montre les trois premières lignes.
  • Langues : ajoutez <script src="/hugerte/langs/onlc/es.js"></script> et language: 'es' pour passer l’interface en espagnol.
