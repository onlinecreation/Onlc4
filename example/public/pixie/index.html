Pixie n’est pas installé

Cette page est l’adaptateur entre ONLC 4 et l’éditeur d’images Pixie, habillé aux couleurs de Pixel•OnlineCreation. Pixie est un produit sous licence commerciale : ses fichiers ne sont pas versionnés dans ce dépôt.

Pour l’installer à partir de l’archive que vous avez achetée :

node example/tools/install-pixie.js /chemin/vers/pixie.zip

Vous pouvez aussi pointer onlc_media_image_editor_url vers une instance déjà déployée — https://pixel.onlinecreation.me par exemple — dans example/public/assets/demo.js.
