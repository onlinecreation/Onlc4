Tous les plugins ONLC branchés sur des API simulées : médias, liens, icônes et éditeur d’images.

API médias API liens API icônes Éditeur Pixel

Que tester ?

  • Blocs : survolez un paragraphe, déplacez-le avec la poignée, utilisez les « + » pour insérer une ligne de colonnes.
  • Médias : bouton Bibliothèque — téléversez, créez un dossier, déplacez un fichier, retouchez une image dans Pixel.
  • Images responsives : redimensionnez une image, puis regardez le HTML enregistré : ni width ni height.
  • Liens : la liste « Lien du site » vient de l’API simulée.
  • Blocs prédéfinis : bouton d’appel à l’action, vidéo, carte, calendrier, widget HTML… puis re-modifiez-les.
  • Script & source : insérez un script (coloration syntaxique), puis ouvrez le code source HTML.
